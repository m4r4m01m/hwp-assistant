# 주제 입력부터 보고서 저장까지 — 2026-10-06

기존 화면은 문서의 문단 수정과 작성 정보 입력을 지원했다. 이번 변경으로 문서함의 **보고서 작성**에서 주제를 입력하고, Codex가 만든 전체 초안·출처를 검토한 다음 **초안 승인·HWPX 만들기**로 새 문서를 저장할 수 있다. 기본 AI는 기존 ChatGPT 로그인으로 실행하는 Codex다.

## 바로 사용하기

실행 중인 테스트 화면: <http://127.0.0.1:15180>. 문서함에서 **보고서 작성**을 누른다.

예시 입력:

> 금융권 해킹 문제에 대한 경영진 보고서를 만들어줘. 국내 공개 사례, 주요 위험, 책임자가 포함된 30·60·90일 대응 계획을 정리하고 사실과 제안을 구분해줘. 공식 출처와 날짜도 표시해줘.

공개자료 검색을 켜고 **Codex로 보고서 초안 만들기**를 누른다. 생성 후 제목, 핵심 요약, 본문, 출처와 확인 사항을 읽고 승인한다. 저장 완료 후 다운로드하거나 편집기로 열 수 있다. 최근 요청에서 이전 초안과 저장 결과를 다시 확인할 수 있다.

서버를 다시 시작하려면 저장소 루트에서 `powershell -NoProfile -File scripts/start-user-review.ps1`을 실행한다. 별도 저장소 `.cache/user-review/data`를 사용한다. 원래 `data`의 문서를 이 테스트에 사용하지 않았다. 실행만으로 Codex를 호출하지 않는다.

## 구현 범위

- `ReportTask`는 소유자, 고정 입력과 해시, 실행 설정, 초안과 해시, 승인·저장 결과를 보관한다. 같은 ID의 같은 요청은 재호출하지 않으며 다른 입력은 거부한다. 취소 후 늦은 생성 결과는 게시하지 않는다. 기존 실행 슬롯을 공유한다.
- 보고서 화면에 주제 예시 3개, 공개자료 검색 선택, 최근 요청, 초안·출처 미리보기, 명시적 승인, 다운로드·편집 연결을 추가했다. 생성 응답 유실은 동일 입력으로 재확인한다. 저장 응답 유실은 먼저 서버의 확정 결과를 읽으며 출력도 유지한다.
- 승인 전에는 문서가 생성되지 않는다. 승인 후 새 빈 rhwp 문서로 문단 틀을 만들며, 미완성 문서는 이름에 `작성 중`을 표시한다. AI 본문은 XML에 직접 삽입하지 않고 문서·선택·원문·서식·인접 문맥 검사를 포함한 기존 exact command로만 적용한다.
- 제목·소제목·본문·출처 서식을 분리했다. 절별 페이지 틀을 만들며 페이지 수 보호를 유지한다. 적용 거부를 자동 축약하거나 강제 적용하지 않는다. 문서 생성이 중단되면 초안을 보존하고 다시 시도할 수 있다.
- 최종 저장은 현재 권한, 문서 잠금, 임대, 기준 버전, 승인 문단, 영수증 연결과 출력 문단을 검증한다. 파일 영속화와 DB commit 후 저장 완료를 표시한다. 과거 파일은 변경하지 않는다.
- 기존 문단 수정, llm 선택 경로와 기본 엔진을 교체하지 않았다. 보고서 요청의 `context_used=false`는 유지한다. 다른 문서·대화의 컨텍스트는 자동으로 넣지 않는다.

## 재현·남은 범위

`scripts/verify-report-live.mjs --allow-codex --url http://127.0.0.1:15180 --out <새 폴더>`는 명시적으로 실제 Codex를 1회 호출하는 별도 시험이다. 일반 E2E는 이 스크립트를 실행하지 않는다. 브라우저 승인 단계는 자동화다.

단위 시험은 취소 응답 장벽, 고정 ID 재요청, 소유자 접근, 승인·저장 재시도, 원본 틀 보존, 잘못된 문단·출력·페이지·영수증 거부를 확인했다. 최종 source 회귀에는 기존 같은 문서의 늦은 응답, 페이지 거부 복구, 승인·영수증·저장 응답 유실, 문서 전환, 인증 시험도 포함된다.

장시간 검증은 이번 요청에 따라 재개하지 않았다. 한컴 데스크톱 왕복, 실제 사람 승인, 정식 배포 엔진 provenance는 별도 확인 대상이다. 현재 결과는 위에서 검증한 진단 엔진을 이용한다.
