# 프로젝트 기준선

문서 정리 v0.5 · 2026-09-25 · 근거: 이전 기획 산출물과 후속 사용자 결정

## 1. 목표와 사용자

회사 바이브코딩 챌린지에서 한글 문서 작성에 익숙하지 않은 직원의 업무 부담을 줄이는 서비스를 개발한다. HWPX 문서를 웹에서 편집·보관·공유하면서 AI 초안과 검토, 재사용 가능한 문서·표·제목·문단 템플릿을 제공한다.

개발자는 2명이다. 구현은 Codex를 활용하고, 설계·작업 분해·검토는 ChatGPT를 활용한다. 서비스가 실행 중 호출하는 AI와 개발 도구를 혼동하지 않는다.

## 2. 확정된 제약

| 구분 | 현재 요구사항 |
|---|---|
| 작업 저장소 | `m4r4m01m/hwp-assistant` |
| 개발 환경 | 회사 외부의 일반 공중망. 사내망 직접 연결을 전제하지 않음 |
| 최종 평가 | 실제 회사 인프라 구축 완료가 아니라 내부 폐쇄망 이식 가능성 |
| 회사 자원 | GPU 서버·Docker 기반 클라우드가 있다는 사용자 설명을 전제로 함. 운영 인프라 구매는 범위 밖 |
| 비용 | 유료 OpenAI API를 사용하지 않음. 신규 유료 API·클라우드·장비 지출을 기본 전제로 하지 않음 |
| AI | 처음부터 로컬/자체 호스팅 오픈 모델 사용. 운영은 사용자가 전달한 사내 모델 “Qwen 3.8” 활용 방향 |
| 모델 식별 | 공식 이름·모델 ID·크기·양자화·API 규격 미확정. “Qwen3-8B”로 바꾸어 쓰지 않음 |
| 형식 | HWPX 우선. HWP 완전 호환은 첫 버전 필수 범위 밖 |
| 협업 | 실시간 공동 편집 제외. 파일 공유·버전 관리는 포함 |
| 최우선 품질 | 웹 편집 후 실제 한글에서 내용·서식·재편집 가능성이 보존되어야 함 |

기존 장비·전력·개발 시간·보유 도구 사용권까지 0원이라는 주장은 하지 않는다. 새 비용이 필요한 설계 변경은 비용·대안·필요성을 별도로 결정한다.

## 3. 기능 범위와 완료 조건

| 영역 | 기능 범위 | 인수기준 초안 |
|---|---|---|
| 편집 | 새 문서, 기존 HWPX 열기, 제목·문단·표 편집, 저장 | 실제 한글에서 요청 변경 및 비대상 내용 보존 확인 |
| 드라이브 | 파일/폴더 목록, 검색·정렬, 업로드/다운로드, 생성·이름 변경·이동·복제·삭제 | 웹에서 파일 관리 흐름 완료. 삭제·복원 방식은 안전성을 기준으로 구현 |
| 공유·버전 | 링크 공유, 버전 목록·다운로드·복원, 한글 수정본 재등록 | 과거 버전 불변, 복원은 새 버전. 동일 파일명만으로 덮어쓰지 않음 |
| AI 초안 | 문서 유형·입력 사실 기반 초안 | 미입력 사실을 임의로 채우지 않고 입력 필요 표시 |
| AI 검토 | 선택 영역 문체·중복·모호성 개선 | 문제 위치·이유·수정안 제공, 승인한 변경만 적용 |
| 규칙 검사 | 확인된 필수 항목·날짜 형식·합계 등 | 코드 검사와 LLM 의견을 구분. 실제 규정 확인 전 가짜 조문을 만들지 않음 |
| 템플릿 | 문서 양식·표·제목·문단의 등록·검색·미리보기·삽입·공유 | 템플릿 삽입 후에도 HWPX 왕복 시험 통과 |
| 이식 준비 | 자체 실행, 설정 분리, 의존성 반입, 격리 환경 시험 | 외부 인터넷 차단 상태에서 실제 AI를 포함한 핵심 흐름 실행 |

기본 공용 작업공간, 휴지통, 자동 저장, 단일 편집 세션과 버전 비교는 안전한 첫 구현을 위한 기존 설계안이다. 세부 권한을 후순위로 두더라도 접근 보호가 불필요하다는 뜻은 아니다.

## 4. 제외·후순위

실시간 공동 편집, 문서 자동 병합, 한글 전체 기능 재구현, HWP 완전 호환, 로컬 폴더 자동 동기화, 전자결재·SSO·세부 부서 권한, 대규모 RAG·모델 학습, 실제 회사 GPU·클라우드 구축은 첫 버전 필수 범위에서 제외한다. NAS나 특정 저장 제품을 의무로 도입하지 않는다.

## 5. 대표 사용자 흐름

**기존 문서:** HWPX 업로드 → 원본 보관 → 웹 편집 → AI 검토·선택 적용 → 새 버전 저장 → 다운로드 → 한글에서 편집·저장 → 대상 문서에 새 버전 업로드.

**새 문서:** 문서 양식 선택 → 사실 입력 → AI 초안 → 템플릿 삽입 → 검토 → 저장·공유 → 한글에서 최종 확인.

회의록·업무보고·추진계획 3종과 블록 약 10개는 과거의 데모 제안이지 확정 수량이 아니다. 대표 문서 선정·합격 판단은 실제 시험 근거로 정한다.
