# 이전 설계서 보관 안내

아래 4개 파일은 2026-09-23 작성된 산출물의 **추출 텍스트 보관본**이다. 원본 MD의 바이트 복사나 원본 ZIP 복원이 아니다. 각 파일 맨 앞에 보관 안내만 덧붙였고, 그 뒤의 확보된 추출 텍스트는 변경하지 않았다.

| 버전 | 보관 파일 | 읽는 목적 |
|---|---|---|
| 초기안 | [internal-doc-assistant-plan.md](internal-doc-assistant-plan.md) | 최초 제안과 이후 변경점의 이력 |
| v0.2 | [internal-doc-assistant-plan-v0.2.md](internal-doc-assistant-plan-v0.2.md) | HWPX 원본·드라이브 중심 설계의 전개 |
| v0.3 | [internal-doc-assistant-plan-v0.3.md](internal-doc-assistant-plan-v0.3.md) | 비용 최소화·로컬 AI 방향 변경 이력 |
| v0.4 | [internal-doc-assistant-plan-v0.4.md](internal-doc-assistant-plan-v0.4.md) | 외부 개발·사내 모델·이식 기준 정리 이력 |

현재 실행 기준은 [현재 문서 인덱스](../README.md)와 [개발 순서](../development-plan.md)다. 과거의 유료 API 계획, 특정 모델 크기 확정, 운영 Ollama 의무화, 회사 환경 우선 실측, 과거 A/B 역할을 다시 적용하지 않는다.

보관본의 외부 출처·라이선스·API 설명은 당시 자료이며 이번 작업에서 최신성 검증을 하지 않았다. 보관본 내부의 옛 패키지 상대 경로 링크는 원래 ZIP을 확보하지 못해 연결되지 않을 수 있다. 최신 문서의 상대 링크와는 별도로 취급한다.

원본 목록 크기와 추출 크기가 다른 것은 알려진 이관 차이다. 각 추출 텍스트와 안내 추가 후 보관본의 SHA-256은 [자료 명세](../references/source-manifest.json)에 기록했다. 해시는 이번에 확보한 텍스트의 무결성 확인용이며 원본 바이트 일치나 문서 사실의 정확성을 증명하지 않는다.
