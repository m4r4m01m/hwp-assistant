- 기준일: 2026-09-25
- 작업 저장소: `m4r4m01m/hwp-assistant`
- 문서 상태: 대화에서 정리한 요구사항과 설계 제안. 애플리케이션 구현·성능·한글 호환 검증의 완료 보고가 아니다.
- 최신 우선순위: **LLM을 먼저 연결해 AI 기능을 검증한다. AI와 시스템을 병렬 진행하는 안을 기준으로 정리하되, 상세 역할과 일정은 아직 확정하지 않았다.**

## 문서 해석 원칙

현재 문서와 보관본이 충돌하면 후속 사용자 지시를 반영한 현재 문서를 우선한다. 특히 v0.4의 순차 개발 단계와 A/B 역할을 최신 실행 순서로 그대로 적용하지 않는다. 당시의 WBS 19개 필수 작업·2개 보류 작업은 이력이며, 실제 GitHub 이슈 생성이나 구현 완료를 뜻하지 않는다.

`확정`은 대화에서 정한 제품 요구사항이다. `제안`은 구현 전 검증할 설계안이며, `미확정`과 `미검증`을 확정 사실이나 완료 성과처럼 표현하지 않는다.

## 공개 저장소 취급

2026-09-25 확인 당시 이 저장소는 공개 상태다. 이 문서 묶음에는 사내 규정 사진 원본, 규정 조문 전문, 실제 업무 문서, 개인정보, 인증정보, 회사 내부 접속 주소, 모델 가중치, 폰트 파일을 포함하지 않는다. 외부 개발과 테스트에는 합성 문서를 사용한다.

기존 ZIP 원본은 파일 목록에서 존재를 확인했지만 이번 이관에서 원본 바이트에 접근하지 못했다. ZIP 내용이나 기존 코드 패키지를 복원·업로드했다고 주장하지 않는다. 자세한 범위는 [이관 기록](references/README.md)을 따른다.
