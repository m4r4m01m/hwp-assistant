## 무엇을 현재 기준으로 읽는가

현재 문서와 보관본이 충돌하면 **후속 사용자 지시를 반영한 현재 문서**를 우선한다. 과거의 순차형 M0→M1→M2→M3 계획과 A/B 역할을 최신 작업 배치로 그대로 적용하지 않는다. 날짜가 없는 단계는 순서이지 기간 약속이 아니다.

`확정`은 대화에서 합의한 요구사항, `제안`은 구현 전에 검증할 선택지다. 제안 아키텍처나 예시 API를 실제 구현이라고 해석하지 않는다. 구현 상태는 향후 실제 저장소 코드·테스트 결과로 확인한다.

보관본은 파일 도구로 확보한 **추출 텍스트**다. 원본 MD와 바이트 동일성을 보증하지 않으며, 과거 ZIP의 구성 파일을 복원한 것도 아니다. 보관본에 남아 있는 옛 상대 경로 링크는 원래 ZIP이 없어 열리지 않을 수 있다.

## 저장·공유 원칙

비공개 저장소라도 사내 규정 사진, 실제 업무 문서, 개인정보, 인증정보, 내부 접속 주소를 이번 문서 묶음에 자동 포함하지 않는다. 모델 가중치와 폰트 파일도 포함하지 않는다. 개발 샘플은 합성 문서로 준비한다.

작업 저장소는 `m4r4m01m/hwp-assistant`이며 앞으로 이 프로젝트의 저장소 작업은 이 경로를 기준으로 한다. 이 기록은 저장소에 남기는 프로젝트 정보이며 ChatGPT 장기 메모리 저장 완료를 뜻하지 않는다.
