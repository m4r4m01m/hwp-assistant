## 검증

- 격리 백엔드 집중 시험 136개, 실제 stdio MCP/API 시험 2개: **138개 통과**. 실제 모델 호출은 포함하지 않는다.
- 프런트 단위 시험 **18개**, TypeScript·앱 빌드·엔진 키트 해시 검증 통과. 실제 WASM fill·selection·block-layout 검사도 통과했다.
- 실제 Chromium/rhwp 블록 시험 **2개 통과**. 배치 왜곡 삽입은 거부하면서 미저장 편집을 유지했고, 정상 제목·요약·표 삽입 및 취소·저장·재열기는 성공했다. AI 호출은 없었다.
- 실제 Codex 호출은 **총 3회**였다. 합성 자료만 사용했고 모두 `gpt-6.1-sol`이었다. 보고서와 대화는 app-server, 문단 수정은 CLI/MCP 경로였다. 유료 대체나 모델 응답 모의는 없었다.
- 보고서는 별첨1의 3쪽 결과를 내용 검토 → 서식 적용 → 서버 저장 → 웹 재열기로 확인했다. 24개 대상, 18개 담당 확인, 6개 미확인, 시범 운영 기간 등 입력 사실을 유지했고 저장·재열기 SHA가 같았다.
- 대화는 미저장 문장의 20건 계획·5건 완료·지출 미승인을 구분했고 서버 문서·버전은 바뀌지 않았다. 최초 답변 직후 live bytes 비교는 시험 스크립트의 컨테이너 선택 오류로 미측정이다. 완료 결과를 재사용해 답변 표시와 문서 불변을 확인했으며 모델을 재호출하지 않았다.
- 문단 수정은 후보 2개 중 첫 후보를 자동 승인해 버전 1→2로 저장했다. 날짜·수치·부정 표현, 원본 버전·비대상 문단·BinData를 유지했고 저장·재열기 SHA가 같았다.

승인 버튼은 합성 시험에서 자동으로 눌렀다. **실제 모델·실제 엔진 검증이며 사람 검수를 뜻하지 않는다.** Hancom, Docker 운영 배포, 격리망 검증은 이번 범위가 아니다.
