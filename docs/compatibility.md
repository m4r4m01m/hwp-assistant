# HWPX 호환성 · 수동 검증표

## 2026-10-20 후속 범위

보고서 화면의 기준서 다운로드·열람용 사본 버튼은 문서 표준 화면으로 연결한다. 이 화면은 해시 고정 원본 12쪽 전체를 읽기 전용 편집기에서 보여주고 별첨 1~3을 편집 가능한 표준의 시작점으로 제공한다. 화면용 데이터의 채우기 없음·표시 메타데이터 정규화와 원본 바이트 보존을 구분한다. 기존 원본 다운로드 API와 과거 파일은 유지한다.

새 보고서의 원문 표준·제목 상자·표지·검토 흐름은 [2026-10-20 구현 기록](report-review-workflow-2026-10-20.md)을 따른다. 실제 Codex 결과와 rhwp 저장·재열기를 검증했지만, 이번 변경본을 Hancom 2018에서 다시 검수한 것은 아니다. 아래 10월 19일 내용은 당시 UI와 호환성 관찰 기록이다.

## 2026-10-19 현재 범위

- 기준서 원본 다운로드는 해시가 고정된 원바이트를 유지한다. 보고서 화면의 **기준서 열람용 사본**은 별도 `/api/document-standard/reference-view`에서 제공하며, 원본에 남은 글자 음영·배경의 `none` 표현만 기존 한컴 2018 시험에서 확인한 `#FFFFFFFF`로 바꾼다. 실제 검정·흰색·다른 RGB와 문서 내용·쪽 설정은 보존한다. 이 사본을 새로 한컴에서 열어 전체 시각 호환을 확인한 것은 아니다.
- 새 보고서 틀과 새 등록 표준 예시에도 같은 채우기 없음 처리를 적용한다. 이미 등록한 표준·과거 문서·동결 미리보기·동일 ID 재확인의 파일과 해시는 변경하지 않는다. 과거 파일은 필요한 경우 별도 사본으로 확인해야 한다.
- 10월 17일에는 실제 Codex 보고서 4쪽과 긴 제목 보고서 20쪽의 한컴 저장·재열기 및 rhwp 재가져오기를 확인했다. [해당 검증 범위](development-handoff-2026-10-17.md#실제-codexhancom확인용-앱)를 참조한다. 아래 과거 표의 미검증 표시는 당시 기록이며 전체 문서군의 완전한 호환 인증으로 해석하지 않는다.
- **색상 해석 차이는 남아 있다.** 10월 18일 설치된 한컴 2018에서 합성 `#FF0000` 글자·채움이 파랑으로 표시되고 `#00FF00`은 초록으로 표시되는 것을 관찰했다. 기준서 제목선의 주황색 표시도 별도 관찰됐다. 다운로드가 색상 XML을 바꾼 결과는 아니며, [색상 관찰 기록](evidence/hancom-color-observation-2026-10-18.json)에 시험의 한계를 보관했다. 전역 RGB 순서를 뒤집는 보정은 하지 않는다.
- 10월 19일 이 PC의 `Hwp.exe` 파일 버전은 기존과 같은 `10.0.0.5060`이었다. 다음 색상 검증은 한컴에서 직접 지정한 알려진 색의 새 저장 사본과 XML을 대조하고, 적용 버전별로 확인해야 한다. [한컴 공식 업데이트 안내](https://help.hancom.com/updates/hoffice100/ko-KR/HOffice2018_update.htm)는 업데이트 경로를 제공하지만 이번 색상 문제가 업데이트로 해결된다고 명시한 근거는 확인하지 못했다. 제품 업데이트·색상 강제 변환을 실행하지 않았다.

이하 내용은 기존 시험 이력으로 보존한다. 원본 다운로드는 저장본 보존 기능이고, 편집기에서 내보내는 현재 초안은 별도의 출력이다. 다운로드 자체가 서버 저장이나 새 한컴 검수를 뜻하지 않는다.

실제 엔진의 합성 문서 시험과 한글 2018에서 단순 문단 문서의 열기·편집·저장·재열기·웹 재가져오기를 실행했다. **검은 배경 결함은 다운스트림 진단 빌드에서 수정했고 새 합성 문서 1건의 내용·시각 확인과 실제 왕복이 통과했다.** 기본 서비스 엔진 반영과 전체 문서군 호환성은 아직 완료하지 않았다. [수정 결과](evidence/hancom-empty-fill-fix-2026-09-27.json), [재현·배포 상태](engine-empty-fill-fix.md).

2026-09-27 후속 확인: 실제 Codex 후보 2의 사용자 승인·rhwp 적용·서버 저장·웹 재열기는 통과했다. 최초 한컴 설치 탐색은 불완전했으며, 사용자 제공 Hwp.exe 경로에서 한글 2018 `10.0.0.5060` 실행을 확인했다. 첫 한컴 실패 기록은 [그대로 보존](evidence/hancom-roundtrip-result-2026-09-27.json)한다. 한컴 기본 문서가 쓰는 없음 값 `#FFFFFFFF`를 엔진의 배경·글자 음영 출력에 적용한 뒤 검은 배경이 사라졌다. 이번 수정 검증에는 실제 AI를 재호출하지 않았다.

확인된 내용 손실은 정상 버전 게시를 중단한다. 원본을 보존하고 복구 후보 파일·엔진 경고를 확보한다. 읽기 전용 또는 저장 차단은 안전 조치이지 호환 성공이 아니다. 일반적인 폰트 대체와 조판 차이는 사람이 판단해야 한다. 실문서를 테스트 저장소에 커밋하지 않는다.

2026-10-06 추가: 합성 제목(굵게·가운데 정렬), 본문, 2×2 표를 실제 rhwp UI에서 만들고 **웹 저장 → 다운로드 → 같은 문서 재업로드 → 재열기**를 3회 반복했다. 매 회 비대상 표 XML·셀 내용·테두리 참조·제목 서식과 이전 버전 해시를 비교했다. 마지막에는 최초 버전 복원이 새로운 8번째 버전을 만들고 원본 바이트와 일치함을 확인했다. 실제 AI나 한컴은 이 시험에 참여하지 않았으며 위 표의 “한컴 반복 왕복”은 여전히 미검증이다.
