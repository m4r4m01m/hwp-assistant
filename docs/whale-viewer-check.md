# 웨일 표 표시 확인 시도 · 2026-09-26

사용자는 이 PC의 한글 데스크톱 설치가 아니라 웨일로 문서를 열었던 것이라고 정정했다. 한글 설치/실행 파일은 확인되지 않았다. 웨일 실행 파일은 `C:/Program Files/Naver/Naver Whale/Application/whale.exe`, 설치 버전 디렉터리는 `4.39.410.14`다.

설치된 웨일을 실행했고 `NAVER - Whale` 창은 발견했다. 그러나 컴퓨터 사용 도구가 해당 창을 선택할 때 아래 오류를 반환했다. 창 목록을 다시 조회하고 재시도해도 동일했다.

```text
window id 68944 no longer belongs to Naver_Whale; current owner is Naver_Whale
```

따라서 **웨일 뷰어에서 파일을 열거나 화면을 비교하지 못했다. 표 깨짐은 재현도 반증도 되지 않았다.** 한글 데스크톱 호환성도 계속 미검증이다.

독립적으로 검사한 `samples/paragraph-and-table.hwpx`의 ZIP CRC는 정상이며, 2×2 표와 4개 셀 주소/범위가 존재한다. 첫 행에 `표 셀 원문 수정`, `두 번째 셀`이 있고 둘째 행은 빈 셀이다. 구조 결과는 `evidence/whale-check-structure.json`에 보존했다. 이 결과는 표 배치, 테두리, 높이, 글꼴 또는 한글 재편집의 정상 여부를 뜻하지 않는다.

셀의 저장 높이 282와 표 전체 높이 2564는 서로 단순 합산되지 않는다. 고정 엔진 소스의 `create_table`은 셀 최소 높이를 위/아래 여백 합으로, 표 전체 높이는 글줄 높이를 포함해 생성한다. 이 수치 차이만을 손상 원인으로 단정하거나 원본 XML을 수정하지 않았다.

다음 비교는 깨짐이 보고된 실제 HWPX와 웨일 화면을 기준으로 수행해야 한다. 웹 화면은 `evidence/table-editor.png`에 남아 있다. 웨일 정상 표시 여부와 한글 데스크톱의 시각/편집 호환 여부는 별도 판정한다.
