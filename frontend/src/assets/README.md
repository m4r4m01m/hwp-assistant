# 금융결제원 UI 자산

`kftc-logo.png`는 금융결제원 공식 웹사이트의 국문 가로형 로고 원본이다.

- 공식 CI 안내: https://kftc.or.kr/intro/prCi
- 원본: https://www.kftc.or.kr/resource/images/common/logo_kftc_blue.png
- 확인·수집: 2026-10-27 (한국 시간)
- 원본 규격: 140 × 39px, 투명 PNG, 4,524 bytes
- SHA-256: `940eef8c0b234379b379379dbfb860d084bb3132d015c36b23b090427a7212d1`

로고의 색상·형태·비율은 수정하지 않았다. 로그인 화면에서 원본 크기 이하로 표시하며, Vite import로 앱에 포함해 실행 중 외부 이미지 요청이 발생하지 않도록 한다. 금융결제원 CI의 권리는 원 권리자에게 있으며 저장소의 일반 코드 라이선스로 재허가하지 않는다.

로그인 UI는 공식 CI 안내의 KFTC Dark Blue `#0062B3`를 버튼·아이콘에, KFTC Sky Blue `#00AFE1`를 문서 장식의 강조선에 사용한다. 나머지 옅은 배경색은 UI 보조색이며 공식 CI 색상이라고 주장하지 않는다. CSS 문서 장식은 로고·금결이 캐릭터를 재작도한 것이 아니다.

[공식 블로그](https://blog.naver.com/PostList.naver?blogId=kftc_official)와 [사용자가 지정한 공식 Instagram 게시물](https://www.instagram.com/p/C_2NCEhSRSI/)에서 금결이 활용을 참고했다. 이번에는 사용자가 허용한 단정한 CI 중심 구성을 선택하여 캐릭터·홍보물 이미지는 포함하지 않았다.


`kftc-symbol.png`는 같은 공식 CI 페이지의 심벌 원본이며 로그인 후 아이콘 사이드바에서 사용한다.

- 원본: https://www.kftc.or.kr/resource/images/contents/img_ci_mark.png
- 확인·수집: 2026-10-27 (한국 시간)
- 원본 규격: 178 × 177px, 투명 PNG, 24,787 bytes
- SHA-256: `b1bab21cdaa6e7e055a59441c6b836430bf6bb62a260fc359ab36fe8a37b57ba`

펼친 공통 사이드바는 기존 가로 로고를126px로, 아이콘 모드는 심벌을30px로 표시하고 원본 비율을 유지한다. 원본의 재작도·자르기·색상 변경이나 외부 이미지 요청은 없다. 위 로고와 동일한 권리자·라이선스 범위가 적용된다.
